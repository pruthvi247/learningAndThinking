## System instructions

System instructions define the highest-level behaviour of the model inside an application.

These can include:

- What the assistant is
- General behavioural boundaries
- Safety requirements
- Tool policies
- Formatting requirements
- Rules that apply across users and projects

The end user usually does not author or directly control this layer.
